# Ванна+ — лендинг

Реставрация ванн жидким акрилом в Томске.
Сайт: https://denii-koz.github.io/vanna-plus/

## Структура

```
index.html      — лендинг
politika.html   — политика обработки персональных данных
soglasie.html   — согласие на обработку персональных данных
img/            — фотографии (фон, «до», «после»)
```

Заявки принимает Яндекс Форма, встроенная в окно записи (`index.html`).
