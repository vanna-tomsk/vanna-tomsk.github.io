# Заявки с сайта → Telegram-бот (Google Apps Script)

Скрипт `Code.gs` развёрнут как веб-приложение в Google Apps Script (аккаунт владельца сайта).
Форма сайта отправляет заявку на адрес веб-приложения (`src/_data/site.json` → `formEndpoint`), скрипт пересылает её в Telegram.

## Свойства скрипта (Настройки проекта → Свойства скрипта)

| Свойство | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен бота от @BotFather — секрет, хранится только здесь |
| `TG_CHAT_ID` | Telegram ID получателей через запятую (узнать — у @userinfobot; получатель должен сначала нажать «Старт» в боте) |

Чтобы добавить получателя — допишите его ID через запятую в `TG_CHAT_ID` и сохраните. Переразвёртывать не нужно.

## Если меняете код

Вставьте новый `Code.gs` в редактор → «Начать развертывание» → «Управление развертываниями» → карандаш → Версия: «Новая версия» → «Начать развертывание». Адрес веб-приложения при этом не меняется.
