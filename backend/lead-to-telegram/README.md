# Заявки с сайта → Telegram-бот

Функция для Yandex Cloud Functions. Сайт отправляет заявку из своей формы, функция пересылает её сообщением в Telegram.

## Настройки функции (переменные окружения)

| Переменная | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен бота от @BotFather — секрет, вводится только здесь |
| `TG_CHAT_ID` | ID чата, куда слать заявки; несколько — через запятую |
| `ALLOWED_ORIGIN` | `https://vanna-tomsk.ru,http://vanna-tomsk.ru` |

## Как узнать TG_CHAT_ID

1. Тот, кто будет получать заявки, открывает бота в Telegram и нажимает «Старт» (или пишет ему любое сообщение).
2. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив токен.
3. В ответе найдите `"chat":{"id":123456789` — это число и есть ID. Для группы ID начинается с минуса.

## Развёртывание

1. Yandex Cloud → Cloud Functions → создать функцию, сделать её **публичной**.
2. Редактор: среда Node.js 22, точка входа `index.handler`, загрузить `index.js` и `package.json`.
3. Таймаут 10 с, память 128 МБ. Заполнить переменные окружения.
4. Скопировать адрес вызова функции (`https://functions.yandexcloud.net/…`) и вписать его в `src/_data/site.json` → `formEndpoint`. После этого на сайте вместо Яндекс Формы появится своя форма.
